# zero-project-V1

Proyek ini adalah repositori untuk **FASTOUR CS** — platform manajemen turnamen Free Fire dan transaksi digital yang aman.

## Tentang Proyek
Repositori ini berisi dokumentasi, struktur kode, dan catatan perkembangan proyek untuk mengelola pendaftaran, room match, sistem pembayaran QRIS otomatis, serta pencatatan turnamen secara real-time.

## Fitur Utama
- **Autentikasi Aman:** Login menggunakan Google OAuth untuk mencegah akun penipuan.
- **Sistem Turnamen & Room:** Pemantauan slot pemain secara live dengan penghitung otomatis (maksimal 4 pemain per room).
- **Pembayaran Otomatis:** Dispatch QRIS merchant secara instan setelah room terisi penuh.
- **Manajemen & Verifikasi:** Kontrol admin untuk pengecekan, tombol "Done", serta pembagian pot hadiah (pot splitting) otomatis.
